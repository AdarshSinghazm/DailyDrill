# 🎯 DailyDrill — Practice Tracker

A minimal, distraction-free daily practice tracker & focus timer built with **React**, **Vite**, and **Tailwind CSS**.

---

## ✨ Features

- **🔥 12-Week Practice Heatmap**: Track your daily consistency across 84 days.
- **⏱️ Full-Screen Focus Timer**: Distraction-free timer mode for Speaking, Writing, and Consumption sessions.
- **📖 Vocab Vault**: Save new words and phrases, and review them using interactive flashcards.
- **📅 Day-Wise History Journal**: View, edit, or delete past practice entries anytime.
- **🔄 Auto-Suggested Topic Cycles**: 10 structured prompts for Speaking and Writing practice.
- **📱 Fully Responsive**: Optimized for desktop and mobile phone screens.

## 🚀 Getting Started

### Prerequisites
- Node.js (v16+)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/AdarshSinghazm/DailyDrill.git
   cd DailyDrill
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run local development server:
   ```bash
   npm run dev
   ```
